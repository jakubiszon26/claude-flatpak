Unofficial community packaging

Claude Desktop for Linux, as a Flatpak

Works on Fedora, openSUSE, Arch, and any other x86_64 distribution with Flatpak. Updates arrive automatically, usually within a day of Anthropic's release.

Install Claude Desktop Opens in GNOME Software or KDE Discover.

Or install from a terminal

flatpak install --user @PAGES_URL@/claude-desktop.flatpakref

Then start Claude from your application menu, or run:

flatpak run com.anthropic.Claude

No Flatpak yet? Follow the setup guide for your distribution first.

Good to know

  • The app comes from Anthropic. This site hosts only a small launcher. During installation, Flatpak downloads Claude Desktop directly from Anthropic's servers and verifies its checksum.
  • It is not sandboxed from your files. Claude Code needs your projects and tools, so the app can read and write your files and run programs installed on your system. The README explains how to restrict this.
  • Not supported by Anthropic. Anthropic officially supports Claude Desktop on Debian-based distributions. Report packaging problems on GitHub.
